# ADR 0004: Authentication and Authorization Roadmap

## Status
Accepted

## Context
This foundational baseline provides the core domain entities, transactional persistence, resilience, outbox relay, and telemetry. It currently operates in an unauthenticated development mode.

## Explicit Security Disclaimer
> **CRITICAL WARNING:** This baseline repository currently has **no authentication or authorization guards** enabled on the `/api/v1/ledger/entries` mutation endpoints. It **must not** be exposed directly to the public internet or production networks without authentication guards in place.

## Target Architecture (Next Phase)
1. **Opaque Session Cookie with Redis Store:**
   - Secure, `HttpOnly`, `SameSite=Strict` cookie containing a cryptographically random session identifier.
   - Redis-backed session store with TTL synchronization.
   - Or standard OpenID Connect (OIDC) JWT verification via an identity provider (e.g., Keycloak, Auth0).
2. **NestJS Guards:**
   - `AuthGuard` attached globally or per controller.
   - Fine-grained RBAC permissions decorator (`@RequirePermission("ledger:write")`).
